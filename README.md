# Typify ✨

**Discover your personality type — beautifully.**

A Gen Z-native personality test app built with Kotlin + Jetpack Compose. Dark mode OLED, gradient result cards, shareable to Instagram/TikTok.

## Features
- 🧠 MBTI Test (60 questions, 16 personality types)
- 📊 Dimension breakdown with confidence scores
- 🎨 Spotify Wrapped-style result cards
- 🔒 100% offline — no data collection
- 🌙 Dark mode OLED aesthetic
- 📱 Shareable results

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose + Material3
- **DB:** Room (local, offline-first)
- **Navigation:** Navigation Compose
- **Min SDK:** 26 (Android 8.0+)
- **Target SDK:** 34

## Build
```bash
./gradlew assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`
